# 验证命令

## 环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| JDK（编译目标） | 21 | `options.release = 21`，Yarn build.6 类名以此为准 |
| JDK（运行 Gradle） | 25+ | Loom 1.19.4 要求 Gradle JVM ≥ 25；官方模板同一组合 |
| Gradle | 9.8.2 | 由 wrapper 自动下载；Loom 1.19.4 要求 ≥ 9.8.0 |
| Node.js | 18+ | 仅用于 Bedrock 脚本离线验证 |

## A. Fabric 模组

```bash
cd fabric
./gradlew --version          # 应显示 Gradle 9.8.2
./gradlew clean build
# 产物：fabric/build/libs/simple_minimap-1.0.0.jar
```

如系统默认 JDK 不是 25，可临时指定运行 Gradle 的 JVM（编译目标仍为 21）：

```bash
JAVA_HOME=/path/to/jdk-25 ./gradlew clean build
```

验证 JAR 内容：

```bash
unzip -p fabric/build/libs/simple_minimap-1.0.0.jar fabric.mod.json
# 应看到 environment:"client"、entrypoints.client 与四项 depends
```

加载到游戏：把上述 JAR 放入 `minecraft/mods/`，使用 Fabric Loader 0.20.1 + Fabric API 0.141.6+1.21.11 启动 1.21.11；按 `M` 打开标记管理。

## B. Bedrock Add-on

```bash
node bedrock/tests/run.mjs
# 预期：合计 PASS=33  FAIL=0，进程退出码 0
```

打包：将 `bedrock/behavior_pack/` 与 `bedrock/resource_pack/` 分别压缩为 `.zip` 后改扩展名为 `.mcpack`，依次导入 Minecraft Bedrock 1.21.130；在世界设置中启用脚本 / Beta API 实验，激活两个包。

进入世界后执行聊天命令 `/simplemap:markers` 打开标记管理（基岩无按键绑定 API，见 docs/03）。

## 清单 / UUID 自检

```bash
python3 - <<'PY'
import json,uuid,pathlib
for p in ['bedrock/behavior_pack/manifest.json','bedrock/resource_pack/manifest.json']:
    d=json.loads(pathlib.Path(p).read_text())
    assert d['format_version']==2
    assert d['header']['min_engine_version']==[1,21,130]
    ids=[d['header']['uuid']]+[m['uuid'] for m in d['modules']]
    assert all(str(uuid.UUID(i))==i and uuid.UUID(i).version==4 for i in ids)
    assert len(set(ids))==len(ids)
    print(p,'OK',ids)
PY
```
